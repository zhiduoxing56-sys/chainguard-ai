# 手动业务交互

应用不强制分析顺序。用户可先查看报告，也可从依赖节点进入详情，或直接查看协议模拟。

## 案例选择

所有页面顶部可选择 Express、Axios 或 Koa。选择立即映射四页数据，保持当前路由。各案例的节点、详情选项卡、GNN 载入标记、协议载入标记、手选协议阶段和复核清单独立保留。刷新仅保留最近选择的案例，分析状态重新初始化。

## 依赖分析

点击默认图节点或全量依赖清单，选中组件并沿根路径高亮。右侧同步包名、声明版本、匹配状态、来源和路径；路径各级可点击。图谱使用固定坐标，缩放/平移与展开/折叠可用。未在默认预览的直接依赖会在选中后加入图谱。

## 智能研判

点击“智能研判”即从本地映射载入当前案例的预置记录。公开事实与模型预置结果分区。切换任意组件不会把根包预置预测冒充为该组件预测，界面明确注明预测目标及当前查看组件。

## 密态分析

点击“密态分析”载入当前案例的模拟材料与授权结果，按钮反馈仅使用短 CSS 过渡。阶段不定时推进，用户手动点击查看五个协议阶段；页面始终保持当前路由。没有真实密码运算和性能数值。

## 风险报告

可随时查看完整公开证据与修复建议。未载入预置 GNN 时显示明确状态并提供本页操作；已载入则使用同一案例记录。复核清单按案例隔离。打印隐藏应用导航与操作按钮，保留证据和分析边界。

## 导航与反馈

鼠标导航、案例选择、来源链接、搜索、通知、使用说明、图谱控制、筛选、研判、协议载入、阶段切换、报告及打印都具备实际响应。仅 `/` 聚焦搜索与 Esc 关闭浮层是全局辅助快捷键；未注册空格、R 或方向键业务操作。
