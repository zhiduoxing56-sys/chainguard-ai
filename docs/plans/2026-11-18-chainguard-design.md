# ChainGuard AI 手动应用设计

按最新用户要求取消自动演示，交付用户可自由操作的四页企业应用。技术为 React + TypeScript + Vite、React Flow、Lucide 和统一 CSS Tokens，纯静态运行。

共享 CaseStudy 数据模型绑定 Express、Axios、Koa 三仓库的版本、tag/commit、声明依赖、局部图、公告、修复建议、根包预置预测和协议输出。Context 持有当前案例及按案例隔离的交互状态，路由由用户点击或浏览器历史控制。

图谱固定坐标，节点选择高亮从根节点到目标的关系路径，右侧同步详情；预览之外的直接依赖选择后加入视图。公开情报与 GNN 预置记录单独标识；切换节点不改变预置记录的根包预测目标。

协议页通过点击载入本地模拟材料，五阶段为用户手动选项。状态反馈采用短 CSS 动画，不推进时间轴、不切路由、不定时操作。

使用浏览器验收 3×4 页面映射、分析载入、状态隔离、无演示快捷键、搜索、来源、图谱和打印。较矮桌面允许滚动；无业务后端、真实计算或安全证明。
